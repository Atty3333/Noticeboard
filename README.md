# Campus Noticeboard Web Application

A robust Java-based web application developed to serve as a digital campus noticeboard. It allows administrators to post announcements, academic schedules, and alerts, while providing students with an easy-to-navigate platform to stay updated.

## 🚀 Features
* **Announcement Management:** Create, update, and categorize campus notices.
* **Role-Based Access:** Differentiated views and permissions for students and administrators.
* **Responsive Web Layout:** Accessible across various devices on the campus network.

## 🛠️ Tech Stack
* **Backend:** Java Servlets, JSP (JavaServer Pages)
* **Server:** Apache Tomcat
* **IDE:** IntelliJ IDEA Ultimate
* **Deployment:** Hosted and deployed on Alwaysdata
